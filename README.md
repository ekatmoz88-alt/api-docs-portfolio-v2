# Документация УММС — инструкция по размещению

## Структура пакета

| Файл | Назначение | Куда класть |
|---|---|---|
| 01_API_ПУБЛИЧНАЯ.md | Описание API (публичное) | На сайт / в портфолио |
| 02_Клиент_ПУБЛИЧНАЯ.md | Описание клиента (публичное) | На сайт / в портфолио |
| index.html | Публичная версия в HTML | На сайт (отдельная страница) |
| 03_API_ПОЛНАЯ.md | API — полная версия, часть 1 (NDA) | Только внутренний контур |
| 03b_ОШИБКИ_API.md | API — полная версия, часть 2: ошибки (NDA) | Только внутренний контур |
| 04_Клиент_ПОЛНАЯ.md | Клиент — полная версия (NDA) | Только внутренний контур |

## Правила

1. Публичные файлы не содержат адресов сервисов, примеров SOAP, тестовых данных
2. Полные файлы содержат служебную информацию — доступ строго ограничен, выдаются только по NDA
3. В публичной HTML-версии используется встроенная подсветка синтаксиса Prism.js (работает полностью автономно, без интернета)
4. При сомнениях: «класть на сайт?» → ответ «нет, это в полную версию»

## Быстрый старт

1. Скопируй публичные файлы (.md + index.html) в папку docs/ на сайте
2. NDA-файлы (.md полные) положи в отдельную папку, доступ к которой ограничен
3. Проверь, что на сайте НЕТ файлов 03, 03b и 04
