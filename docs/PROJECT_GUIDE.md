# API Documentation Portfolio V2: обзор проекта

## Назначение

Портфолио API-документации и архитектуры документационного портала. Включает OpenAPI 3.1, REST-примеры, материалы по legacy SOAP, проверку контрактов и публикацию Jekyll-сайта.

## Основные материалы

- `openapi/openapi.yaml` — Orders API.
- `openapi/navigation-api.yaml` — Navigation API.
- `index.md` — главная страница.
- `legacy-soap-api-review.html` — обзор SOAP-интеграции.
- `umms-enterprise-soap-client.html` — кейс SOAP-клиента.
- `.github/workflows/ci.yml` — проверки и публикация.

## Инструменты

OpenAPI 3.1, YAML, Spectral, Redocly CLI, Node.js/npm, Jekyll, GitHub Actions и GitHub Pages.

## Ограничения

Это портфолио-демо. API и SOAP-кейсы иллюстративны и не дают доступа к действующим системам.
