# Портфолио технического писателя

В этом репозитории собраны примеры моих работ в области технического писательства, документирования API, архитектурного анализа спецификаций и технического редактирования.

## Онлайн-документация (Сайт проекта)

| Страница | Описание |
|------|-------------|
| **[Главная страница](https://github.io)** | Главный лендинг со встроенной спецификацией Orders API (Redocly) и навигацией |
| **[Обзор Legacy SOAP API](https://github.iolegacy-soap-api-review)** | Ретроспективный аналитический обзор устаревшей SOAP-документации |
| **[Документация UMMS SOAP Client](https://github.ioumms-enterprise-soap-client)** | Документация SOAP-клиента (анонимизированный кейс-стади) |

## Демонстрируемые навыки

| Область | Детали |
|------|---------|
| Документирование REST API | OpenAPI 3.0, Redocly, проектирование примеров запросов/ответов |
| Документирование SOAP API | Анализ WSDL/XSD схем, структура XML-пакетов, обработка ошибок (Faults) |
| Аудит документации | Gap-анализ, подготовка структурированных рекомендаций по миграции |
| Локализация | Двуязычная документация (английский — основной, русский — дополнительный) |

## Технологии и инструменты

| Инструмент / Стандарт | Применение в проекте |
|-----------------|-------|
| OpenAPI 3.0 (YAML) | Спецификация Orders API |
| Redocly | Статический рендеринг документации |
| HTML5 / CSS3 | Кастомная верстка страниц кейсов |
| GitHub Pages | Хостинг и автоматическое развертывание (на базе Jekyll) |
| SOAP / WSDL / XSD | Документирование интеграционных сервисов предприятия |

## Структура репозитория

| Путь | Назначение |
|------|---------|
| `_config.yml` | Конфигурационный файл движка Jekyll |
| `index.md` | Динамическая главная страница портфолио |
| `legacy-soap-api-review.html` | Страница аналитического обзора Legacy SOAP |
| `umms-enterprise-soap-client.html` | Страница документации UMMS SOAP-клиента |
| `openapi/openapi.yaml` | Спецификация Orders API в формате OpenAPI |
| `README.md` | Главный файл описания репозитория (Английский) |
| `README.ru.md` | Данный файл описания (Русский) |

## Примечание к демо-материалам

> **Примеры в Orders API используют заглушки эндпоинтов (`://example.com`)** исключительно в демонстрационных целях. Они не являются живыми рабочими сервисами.
>
> Данные в SOAP-кейсах **полностью анонимизированы**: конфиденциальные URL-адреса, учетные данные и продуктовые XML-схемы были удалены.
