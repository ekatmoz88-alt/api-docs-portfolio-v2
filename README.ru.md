## Важное примечание (Demo Note)

> **Примеры Orders API используют тестовые эндпоинты (`api.example.com`)** и предназначены исключительно для демонстрации документирования. Это не рабочие продакшн-сервисы.
>
> Все SOAP-примеры **обезличены**: конфиденциальные URL, учетные данные, продакшн-схемы XML и персональные данные удалены. Это демонстрирует практику документирования без раскрытия закрытой информации.

## О портфолио

Репозиторий создан как **портфолио Technical Writer / Documentation Developer** для демонстрации:
- Умения писать понятную, структурированную документацию для REST и SOAP;
- Понимания стандартов (OpenAPI, WSDL, XSD);
- Навыка поиска пробелов в документации и предложения решений;
- Ориентированности на аудиторию (разработчики — основные читатели);
- Рабочего процесса docs-as-code (Git, GitHub Pages, статическая генерация).

## Автор

Портфолио технического писателя. Создано для демонстрации ясности, структуры и ориентированности на читателя.
